# DOM — 셋 중 하나를 고른다

<!-- 이 파일은 뼈대가 아니다. 셋 중 무엇을 쓸지 고르는 안내다 — 이것을 그대로 쓰면 필수 절이 하나도 없다 -->

DOM은 **문서 셋**이다. 필수 절이 미결사항 말고는 하나도 겹치지 않아 뼈대가 셋이다([[SYNC-STD-001]] 2.6).

| 무엇을 쓰나 | 언제 | 뼈대 | MCP로 받기 |
|---|---|---|---|
| 도메인 모델 | 6단계에서. UC·INFRA 뒤 | `DOM-도메인.md` | `get_template(코드, "DOM", subtype="도메인")` |
| 클래스 명세 | **8 API 뒤에 돌아와서.** 메서드는 API가 정한다 | `DOM-클래스.md` | `get_template(코드, "DOM", subtype="클래스")` |
| ERD·DD | 클래스 명세 뒤. 테이블은 엔티티에서 나온다 | `DOM-ERD.md` | `get_template(코드, "DOM", subtype="ERD")` |

- **한 번에 셋을 쓰지 않는다.** 사이에 다른 단계가 낀다. 문서 하나를 만들면 멈춘다(STD-001 1.8)
- 제목에 「도메인」「클래스」「ERD」 중 하나를 넣는다 — 그것으로 무엇인지 안다(없으면 위반)
- 세 문서는 항목 이름을 맞춘다 — 도메인 `Document`, 클래스 `Document`, 테이블 `documents`
