# API — 둘 중 하나를 고른다

<!-- 이 파일은 뼈대가 아니다. 둘 중 무엇을 쓸지 고르는 안내다 — 이것을 그대로 쓰면 필수 절이 모자란다 -->

API는 **문서 둘**이다. 필수 절이 다르므로 뼈대도 둘이다([[SYNC-STD-001]] 2.8).

| 무엇을 쓰나 | 필수 절 | 뼈대 | MCP로 받기 |
|---|---|---|---|
| REST | 규칙 · 에러 · 엔드포인트 · 미결사항 | `API-REST.md` | `get_template(코드, "API", subtype="REST")` |
| MCP | 규칙 · 도구 · 에이전트 순서 · 미결사항 | `API-MCP.md` | `get_template(코드, "API", subtype="MCP")` |

- 제목에 「REST」「MCP」 중 하나를 넣는다 — 그것으로 무엇인지 안다(없으면 위반)
- 한 문서에 둘을 겸하지 않는다. 절 제목을 괄호로 겸업시키면(`엔드포인트 (또는 도구)`) 사람은 읽어도 검사기는 못 읽는다
